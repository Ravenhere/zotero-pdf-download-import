# PDF 下载导入助手

监测指定文件夹。新 PDF 写入稳定后，弹窗让你选分类并确认导入 Zotero。原文件会保留，去重限于本插件的导入记录。

## 适用环境

- 已测试：Apple 芯片 Mac（型号标识 Mac17,3）、macOS 26.6、Zotero 10.0.9。测试使用隔离文库，确认与取消由脚本模拟。
- 内置文件事件监测程序面向 Apple Silicon（arm64），最低目标系统为 macOS 26.0。其他 Apple 芯片 Mac 尚未实测。
- 内置监测程序启动失败时，插件改用约每秒一次的检查。Intel Mac、较旧 macOS、Windows 和 Linux 尚未验证。

## 安装与使用

1. 下载 [v1.0.0 安装包](./zotero-pdf-download-import-1.0.0.xpi)。在 Zotero 打开 **工具 → 插件**，从齿轮菜单选择 **从文件安装插件**。
2. 打开 **工具 → PDF 下载导入助手设置…**，选择自己的下载目录和默认分类。如 macOS 提示访问该文件夹，允许该项访问。
3. 保持 Zotero 运行，下载新 PDF，在弹窗里选分类并确认。首次设置时已有的 PDF 会跳过。
